# Forum 360: админка, запуск и передача заказчику

## Что появилось

Сайт теперь может работать как full-stack приложение:

- публичный сайт остаётся React/Vite;
- закрытая админка доступна по `/admin`;
- backend на Node.js хранит контент в SQLite-файле;
- фотографии, загруженные через админку, сохраняются в `storage/uploads`;
- текущий контент сайта лежит стартовым снимком в `content/site-content.json`.

Важно: папка `storage/` не коммитится. Это рабочие данные сервера: база, сессии и загруженные фото.

## Локальный запуск

1. Установить зависимости:

```bash
npm install
```

2. При необходимости пересоздать стартовый контент из текущих TS-данных:

```bash
npm run seed:content:force
```

3. Запустить сайт вместе с backend:

```bash
npm run dev:full
```

4. Открыть:
- сайт: `http://127.0.0.1:5174/`;
- админка: `http://127.0.0.1:5174/admin`.

Локальные dev-доступы, если пароль не задан через env:

- логин: `admin`;
- пароль: `admin`.

## Как задать нормальный пароль

Сгенерировать хеш:

```bash
npm run admin:hash -- "СЮДА_НОВЫЙ_ПАРОЛЬ"
```

На сервере использовать переменные окружения:

```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD_HASH=полученный_хеш
SESSION_SECRET=длинная_случайная_строка
PORT=8787
```

В продакшене нельзя оставлять пароль `admin`.

## Что заказчик сможет менять

В админке есть вкладки:

- `Общие блоки`: hero, “О компании”, подвал и контакты;
- `Команда`: заголовок блока, подзаголовок, тексты, должности, статистика и подробный опыт;
- `Кейсы и фото`: тексты кейсов, ссылка ЕИС, порядок кейсов, загрузка/удаление/сортировка фотографий.

После изменения нужно нажать `Сохранить изменения`. После сохранения изменения сразу видны на сайте.

## Деплой на reg.ru / VPS

Для этой версии нужен не обычный статический хостинг, а VPS/облачный сервер с Ubuntu и Node.js 22+.

Общая схема:

1. Купить домен на reg.ru.
2. Купить VPS/облачный сервер.
3. В DNS домена создать A-записи:
   - `@` → IP сервера;
   - `www` → IP сервера.
4. На сервере установить Node.js 22+, Nginx и certbot.
5. Скопировать проект на сервер.
6. Выполнить:

```bash
npm ci
npm run seed:content
npm run build
```

7. Запустить Node-сервер через systemd или PM2.
8. Настроить Nginx как reverse proxy на `127.0.0.1:8787`.
9. Подключить SSL через Let’s Encrypt.

Пример Nginx:

```nginx
server {
  server_name example.ru www.example.ru;

  location / {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

## Бэкапы

Бэкапить нужно папку `storage/`:

```bash
tar -czf forum360-backup-$(date +%F).tar.gz storage/
```

В ней находятся:

- `forum360.sqlite` — тексты, кейсы, порядок фото, сессии;
- `uploads/` — фото, загруженные через админку.

Перед крупными изменениями в админке лучше делать свежий бэкап.

## Проверки перед передачей

```bash
npm run build
npm run test:e2e
```

После деплоя вручную проверить:

- сайт открывается по домену;
- `/admin` открывается по домену;
- вход работает только с реальным паролем;
- можно изменить текст и сохранить;
- можно загрузить фото в кейс;
- фото появляется в галерее;
- SSL активен, адрес начинается с `https://`.
